# Music Playlist Manager

A sleek and efficient web application designed to help users seamlessly organize, manage, and curate their favorite music tracks into custom playlists. Whether you are building the perfect workout mix or a relaxed evening vibe, this tool makes playlist curation effortless.

## 🚀 Features

* **Custom Playlists:** Create, rename, and delete personalized music playlists.
* **Track Management:** Easily add, rearrange, or remove songs within any playlist.
* **Search & Filter:** Quickly find tracks by title, artist, or genre.
* **Intuitive UI:** Clean and responsive interface built for an optimal user experience across desktop and mobile devices.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Version Control:** Git & GitHub
